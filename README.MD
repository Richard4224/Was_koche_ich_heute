# Was koche ich heute?

#### Video Demo: <URL HERE>

#### Description:

*"What shall I cook today?"*: a German recipe website that suggests what to cook and, with a wink, asks the stars for advice.

You open the page and find yourself in space, looking at the moon in its real, current phase. Underneath it you read the signs of the sky: the moon phase, the season and the live weather where you are. When you scroll down, you descend through a starry night sky, past a plane and a flock of birds, towards mountains and a distant city glowing on the horizon, and into a forest of giant firs. Down on the forest floor stands a little stone cottage with glowing windows and a smoking chimney: someone is cooking. Next to it are the recipe book and the *dish of the day*.

My CS50x final project. I also want to use it at home, which is why everything a visitor sees is in German.

## What it can do

- **Signs of the sky:** the current moon phase (drawn as an actual moon), the astronomical season and the live weather with "feels like" temperature and place name.
- **Your location, if you allow it:** the browser shares its position. If it doesn't (or times out), the server guesses the city from the IP address, and if that fails too, it falls back to Berlin. The season flips on the southern hemisphere.
- **318 recipes** in an SQLite database, each with ingredients, amounts, time, season and step-by-step instructions.
- **Recipe pages with adjustable servings:** all amounts are recalculated, including amounts mentioned inside the instructions, and shown in kitchen-friendly form (`¼ Zwiebel`, `1,2 kg`, `2 Prisen`, `3 Tage 3 Std.`).
- **Search and filters** that update the results while you type: by name, vegan, vegetarian, gluten-free, by what you have at home and by what you don't want. Pick your ingredients and the recipes that miss the fewest come first, each card saying what's missing ("Es fehlt: Sahne") or "Alles da".
- **A quick bar of common ingredients:** one click adds one ("hab ich"), the minus next to it excludes it ("ohne").
- **Results scroll in their own box** and load more as you reach its end, so the page stays where it is.
- **Coming back from a recipe** returns you to the same search, scrolled to the same spot.
- **Dish of the day** on the start page.
- **Works on phones:** the layout adapts, and visitors who prefer reduced motion get a still picture.

## Getting started

You need Python 3 and Flask (developed with Python 3.14 and Flask 3.1).

```bash
pip install flask
python -m flask run
```

Then open http://127.0.0.1:5000.

- **The database builds itself.** If `recipes.db` doesn't exist, the app creates it from `schema.sql` and `seed.sql` on first use. After changing either file, delete `recipes.db` and it will be rebuilt. The database is in `.gitignore`.
- **Location:** browsers only share the location on `localhost` or over HTTPS. If you block it, the IP fallback described above kicks in.
- **The scenery** (fir rows, cottage, horizon with the city) is generated by a script. To change it, edit and run:
  ```bash
  python tools/generate_scenery.py
  ```

## Design decisions

### Data

- **Three tables:** `recipes`, `ingredients` and `recipe_ingredients` in between, because a recipe has many ingredients and an ingredient appears in many recipes. Storing ingredients as text in the recipe would make filtering by ingredient impossible ("Zwiebel" vs. "Zwiebeln").
- **Recipe and ingredient names are unique.** Every ingredient exists exactly once, which is what filtering by ingredient relies on. It also lets `seed.sql` link recipes and ingredients by name instead of remembering ids.
- **Vegan, vegetarian and gluten-free are stored per ingredient,** not per recipe. A recipe is vegan if all of its ingredients are. One deliberate call: Parmesan and Pecorino count as not vegetarian (animal rennet).
- **Amounts are numbers** (`REAL`), always for the recipe's base `servings`, so they can be scaled. `NULL` means "to taste" (salt, pepper, …).
- **Amounts inside the instructions are placeholders** like `{100 g}` or `{2-3 EL}`, so "add 100 g flour" scales along with the ingredient list.
- **Servings are whole numbers,** so a cake for one springform scales to 2 springforms, never 1.5.
- **Foreign keys are switched on** (`PRAGMA foreign_keys = ON`) for every connection. SQLite doesn't check them by default.
- **Python's built-in `sqlite3`** instead of the CS50 library, so the project needs nothing beyond Flask.

### Search and filters

- **One search, two ways in.** The start page reads the search from the URL (`/?q=suppe&vegan=1&zutat=Zwiebel`), so it works without JavaScript and survives a reload. With JavaScript, `/recipes` returns just the cards and the page swaps them in while you type, keeping the URL up to date.
- **Case doesn't matter, umlauts included.** SQLite's `LIKE` only ignores case for A–Z, so the app registers Python's `str.casefold` as an SQL function. `%` and `_` are escaped, so they are searched for literally.
- **Diets are checked in SQL:** a recipe is vegan if there is no ingredient in it that isn't (`NOT EXISTS`).
- **"What do I have at home?" ranks instead of excludes.** Requiring every ingredient would almost always find nothing, so all recipes using at least one of your ingredients are found, sorted by how many ingredients are missing. Salt, pepper and anything "to taste" (no amount) never count as missing.
- **Excluding ingredients is strict:** a recipe containing any of them is left out (`NOT EXISTS … IN (…)`). An ingredient can be either "have" or "without", never both; choosing one takes it out of the other.
- **Ingredients are picked from the list of all 352,** so only names that really exist end up in the search. Typing "Ei" on the way to "Eigelb" doesn't add "Ei" too early: only choosing a suggestion or pressing Enter adds one.
- **The quick bar** shows the 16 ingredients used in the most recipes, counting only real amounts, so salt, pepper and spices "to taste" don't crowd it. Its links work without JavaScript too.
- **12 results at a time in a scrolling box.** Reaching its end loads the next 12; `overscroll-behavior: contain` keeps the page from scrolling along. How many are shown is kept in the URL, and the scroll position inside the box is remembered, so coming back from a recipe you land on the same card.

### Moon, season, weather

- **Moon phase:** calculated from a known new moon (6 January 2000) and the length of a lunar cycle (29.53 days), split into 8 phases. Accurate to about one day, which is enough for a page that asks the stars for advice.
- **Season:** astronomical (spring begins around 20 March), using fixed dates that can be a day off in some years. South of the equator it is flipped.
- **Weather:** from [Open-Meteo](https://open-meteo.com), which needs no API key. Results are cached for 15 minutes per location (rounded to about 1 km) so not every page load asks the API.
- **Place names:** from OpenStreetMap's Nominatim, which asks every app to identify itself, so requests carry a user agent with this repository's URL.
- **The page loads first, the weather follows.** The browser's location can take a few seconds, so the start page shows "Die Sterne befragen das Wetter …" and fills in the weather via JavaScript.

### Look and feel

The vibe I wanted: mysterious and enchanted, a moonlit night in a forest lit by lanterns, a bit like Zelda's Lost Woods with a hint of the colourful fantasy of *No Game No Life*. Deliberately not a run-of-the-mill recipe site.

- **The start page is a journey,** and the content follows it: the sky shows the signs of the sky, and the cottage, where someone is cooking, is where you find the recipes.
- **Colours:** night blue and purple, warm lantern amber for anything cooking-related (amounts, times, buttons), and a little cyan and lavender for magic.
- **Glass panels** let the scenery shine through behind the content.
- **Fonts:** Fraunces for headings (a soft serif; an earlier, pointier font didn't fit) and Source Sans 3 for text.
- **Generated scenery:** firs, the stones and thatch of the cottage, the gnarled tree and the city are generated with fixed random seeds. That makes them look natural instead of copy-pasted, while every run produces the same result. Each row of firs repeats at the same spacing, with the far row shifted by half a gap so every far tree stands between two close ones.
- **Recipe pages stay calm:** a simple night sky. That's where you cook, not explore.

### Code

- **Content in German, code in English:** everything visitors see is German; names, comments and this README are English.
- **Templates only display.** Rounding, formatting and scaling happen in Python, so templates contain almost no logic.
